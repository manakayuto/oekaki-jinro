# 絵描き人狼

ひとり1筆ずつ絵を描いて、お題を知らない人狼を見つけ出すパーティーゲーム。スマホのブラウザで遊べます。

- `index.html` — オンライン版。1人が部屋を作り、他の人は部屋コード・QR・招待リンクで各自のスマホから参加（3〜10人）。
- `local.html` — 1台のスマホを回して遊ぶ版（`./build.sh` で `pass-and-play.src.html` から生成）。
- `fx.js` — 市民・人狼の演出、効果音、振動（両方の版で共通）。人狼の顔と、市民の夜明けの村の絵もSVGでここに描いています（外部画像なし）。
- `topics.js` — お題の一覧（13ジャンル・473語、両方の版で共通）。最近出たお題はしばらく出ないようにしています。

## しくみ
- サーバーは持たず、部屋の親のスマホがゲームの進行を管理し、参加者のスマホとWebRTC（PeerJS）で直接つながります。
- 接続の仲介にはPeerJSの公開サーバー（0.peerjs.com）を使います。
- 親のスマホは役職を全員分持っているため、ブラウザの開発者ツールを使えば中身を覗けます（画面には出しません）。
- ゲーム中に親がページを閉じると全員の進行が止まります。同じタブで開き直すと再開できます。
